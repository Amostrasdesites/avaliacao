PADARIA VILA MOREIRA — SITE OFICIAL
=====================================

ESTRUTURA DE ARQUIVOS:
- index.html   → Páginas, textos, produtos e conteúdo
- estilo.css   → Cores, fontes, design e aparência
- script.js    → Funcionalidades, entrada, WhatsApp, filtros
- README.txt   → Este arquivo de instruções

COMO USAR:
1. Mantenha todos os arquivos na MESMA pasta
2. Dê dois cliques em index.html para abrir no navegador
3. Para colocar na internet: envie os 4 arquivos para a hospedagem

COMO EDITAR:
✅ Alterar preços/produtos → editar index.html
✅ Mudar cor/fonte → editar estilo.css
✅ Trocar número do WhatsApp → editar script.js (seção CONFIG no topo)
✅ Alterar endereço/horário → editar index.html

IMPORTANTE:
- O nome do cliente fica salvo automaticamente
- Não há opção de alterar nome após entrada
- Mesmo nome = número único diferente → sem confusão
